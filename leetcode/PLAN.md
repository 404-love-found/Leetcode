# 面试刷题 + 深度学习 学习计划（每天 1 小时）

## 每天 1 小时怎么分配

| 时间 | 做什么 |
|---|---|
| 10 分钟 | **复习**：不看答案，重写昨天的题 |
| 40 分钟 | **新题**：先自己想 15–20 分钟，想不出来再要提示（不要直接看答案） |
| 10 分钟 | **总结**：写下题型、关键思路、时间/空间复杂度 |

每周安排：周一到周五刷算法；周六学深度学习；周日把本周做错的题重做一遍。

## 深度学习路线（每周六）

1. 前向传播改成矩阵写法（`W @ x + b`），理解张量的形状（shape）
2. 损失函数 + 梯度下降，手推反向传播
3. 用 numpy 从零写一个两层 MLP，并完成训练
4. PyTorch 基础：tensor、autograd、`nn.Module`、训练循环
5. CNN（卷积、池化），在 MNIST 上实践
6. RNN / LSTM → Attention → Transformer
7. 面试高频概念：过拟合、正则化、Dropout、BatchNorm、优化器（SGD / Momentum / Adam）、梯度消失与梯度爆炸
